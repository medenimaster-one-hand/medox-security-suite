# 🛡️ MEDOX SOC Center & Cybersecurity Lab

Welcome to my central repository for system monitoring, threat detection, and defense automation. This project represents an integrated **SOC (Security Operations Center)** environment designed to analyze malicious activities, detect intrusions (IDS), and proactively protect Linux systems.

## 🚀 Key Features

* **Whitehat Hunter & Shield:** Automated tools for deep system scanning against rootkits (`chkrootkit`, LKM malware) and active system hardening.
* **Real-Time Threat Detection:** Live traffic monitoring and analysis of known payloads (such as *Metasploit Meterpreter* on port `4444`).
* **Network Radar:** Advanced monitoring of open sockets, network interface promiscuous modes (`ifpromisc`), and suspicious packet sniffers.
* **Automated Backup & Optimization:** Scripts for secure system archiving (`tar.gz`) and RAM cache clearing.
